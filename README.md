# SolaLauncher

Десктопное приложение (**Electron**) — не браузерная страница, а отдельная программа со своим окном, без адресной строки и вкладок браузера. Собирается в обычный `.exe` / `.dmg` / `.AppImage`, который можно передать другу — ему не нужно ставить Node.js.

## Что уже реализовано

- Своё окно без стандартной рамки Windows/macOS (кастомный титлбар, свернуть/закрыть)
- Настройки (шестерёнка): RAM, цвет градиента, путь к `java` (необязательно — если не указан, лаунчер сам скачивает нужную версию Java, см. ниже)
- Чёрно-розовый градиент, следующий за курсором; частицы за курсором + всплеск при клике на лого
- Список версий подтягивается из GitHub-репозитория [MagicDippyEgg/Minecraft-Version-Archive](https://github.com/MagicDippyEgg/Minecraft-Version-Archive) (все официальные релизы Mojang)
- Локальный скин: кнопка "Загрузить скин" открывает диалог выбора PNG-файла с диска, картинка сохраняется в папке данных приложения и показывается в лаунчере (превью головы персонажа)
- **Реальный запуск Minecraft**:
  - метаданные версии (библиотеки, ассеты, аргументы JVM/игры, main class) подтягиваются из официального манифеста Mojang (`piston-meta.mojang.com`) по имени версии
  - библиотеки и natives скачиваются и кэшируются локально, natives распаковываются автоматически для старых версий (LWJGL 2)
  - ассеты (индекс + объекты) скачиваются с `resources.download.minecraft.net`, для очень старых версий (pre-1.6) раскладываются в `assets/virtual/legacy`
  - собирается classpath и JVM/game-аргументы по официальной схеме подстановки Mojang
  - используется офлайн-режим (никнейм + сгенерированный `OfflinePlayer:<ник>` UUID, как в оригинальном лаунчере при игре без покупленного аккаунта)
  - процесс `java` запускается через `child_process.spawn`, лог игры доступен в консоли лаунчера (кнопка "консоль" появляется после старта), прогресс закачки библиотек/ассетов показывается прогресс-баром
- **Автоматический подбор Java под версию** (`lib/java-runtime.js`): разным версиям Minecraft нужна разная Java (например, старым — Java 8, версиям начиная с 1.20.5 — Java 21, самым новым — Java 25), и запуск с неподходящей Java — самая частая причина мгновенного краша ("закрыт, код 1"). Если путь к `java` в настройках не указан, лаунчер:
  - смотрит поле `javaVersion` в официальных метаданных выбранной версии (то же, что использует Mojang);
  - скачивает нужный рантайм из официального манифеста Java-рантаймов Mojang (`launchermeta.mojang.com/.../java-runtime/.../all.json` — тот же источник, которым пользуется оригинальный лаунчер) под текущую ОС/архитектуру;
  - кэширует его в `userData/minecraft/runtime/<компонент>/<платформа>` и при следующих запусках переиспользует, лишь сверяя версию по хэшу (без учёта Java пользователю вообще не нужно ничего ставить самому).
  - если задать свой путь к `java` в настройках — используется он, автоскачивание при этом не выполняется.

Всё хранится в папке пользовательских данных приложения (`app.getPath('userData')/minecraft`) — версии, библиотеки, ассеты, natives.

> Важно: локальный скин, загруженный в лаунчере, виден только в самом лаунчере (превью аватара) и не передаётся ни в какую внешнюю систему. На большинстве серверов (в первую очередь на серверах, работающих в лицензионном режиме) он отображаться не будет — отображение скина другим игрокам на сервере зависит от того, что поддерживает сам сервер.

## Запуск (для разработки)

1. Установи [Node.js](https://nodejs.org) (LTS, если ещё не установлен) и Java (JRE/JDK) — она нужна для самой игры, не для лаунчера.
2. В папке проекта выполни:
   ```
   npm install
   npm start
   ```
3. Откроется окно SolaLauncher.

## Сборка в готовый .exe / .app / AppImage

```
npm install
npm run build:win     # для Windows -> dist/SolaLauncher Setup.exe
npm run build:mac     # для macOS -> dist/SolaLauncher.dmg
npm run build:linux   # для Linux -> dist/SolaLauncher.AppImage
```

Готовый установщик появится в папке `dist/`. Собранное приложение уже не требует ни Node.js, ни ручной установки Electron у того, кто им пользуется — только Java для самого Minecraft.

> Собирать под конкретную ОС проще всего на этой же ОС (electron-builder может кросс-собирать, но для Windows/macOS иногда нужны доп. инструменты — если что, спроси).

## Структура проекта

```
SolaLauncher/
├─ main.js              # главный процесс Electron: окно, IPC, запуск игры
├─ preload.js            # безопасный мост между окном и main.js
├─ index.html            # весь интерфейс (разметка + стили + скрипт)
├─ package.json
└─ lib/
   ├─ http-utils.js       # GET JSON / POST form / скачивание файлов с редиректами
   ├─ java-runtime.js     # автоподбор и скачивание нужной Java под версию игры:
                           #   - определение компонента (jre-legacy/alpha/beta/gamma/delta/epsilon)
                           #     по javaVersion из метаданных версии
                           #   - скачивание и кэширование официального рантайма Mojang
                           #   - поиск исполняемого java внутри установленного рантайма
   └─ launcher-core.js    # вся логика запуска Minecraft:
                           #   - манифест версий Mojang, метаданные версии
                           #   - подбор Java через java-runtime.js (если путь не задан вручную)
                           #   - скачивание библиотек, распаковка natives
                           #   - скачивание ассетов (+legacy-режим)
                           #   - сборка JVM/game-аргументов, offline UUID
                           #   - spawn процесса java
```

## Известные ограничения

- Java вручную ставить не нужно — лаунчер сам скачивает версию, подходящую конкретной версии игры (8/16/17/21/25 — какая нужна). Свой путь к `java`/`javaw` в настройках нужен только для нестандартных случаев (например, собственная сборка JVM).
- Официальные рантаймы Java от Mojang покрывают Windows (x64/x86/arm64), macOS (Intel/Apple Silicon) и Linux x64/x86. Под Linux arm64 готового рантайма у Mojang нет — на такой системе нужно поставить Java самостоятельно и указать путь в настройках.
- Модпаки/Forge/Fabric не поддерживаются — только ванильные версии из архива MagicDippyEgg.
- Список версий, метаданные библиотек/ассетов и рантаймы Java запрашиваются из интернета (GitHub API, piston-meta.mojang.com, resources.download.minecraft.net, launchermeta.mojang.com) — без сети лаунчер не сможет показать список версий или скачать ещё не скачанную версию/Java (уже скачанные версии и Java запускаются из локального кэша без сети).
